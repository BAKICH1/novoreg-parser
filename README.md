# НовоРег Радар РФ — Парсер новых ИП и ООО с телефонами (24/7 + Here.now)

Полнофункциональный гибридный парсер **«2-в-1»** новых регистраций **ИП** и **ООО** по всей России с автоматическим поиском и нормализацией деловых телефонов (`+7 (XXX) XXX-XX-XX`), веб-интерфейсом CRM-мониторинга на хостинге **[Here.now](https://here.now)** и бесплатной круглосуточной автоматизацией через **GitHub Actions (cron)**.

## ⚙️ Архитектура парсера «2-в-1»

Так как в бесплатных PDF-выписках ФНС личные телефоны скрыты, система объединяет сразу два контура сбора и обогащения легальных деловых контактов:

### Контур 1 — Бесплатные открытые источники (работает сразу «из коробки» без ключей)
1. **`FindOrgFrontierCollector` (`parser/collectors/open_egrul.py`)** — поразрядный бинарный спуск по префиксам ОГРН текущего года (`126<КодРегиона>…`), который автоматически находит самые свежие последовательные регистрации ООО по регионам РФ и извлекает ИНН, ОГРН, КПП, дату присвоения, ФИО руководителя, ОКВЭД и адрес.
2. **`FnsDirectCollector` (`parser/collectors/open_egrul.py`)** — прямой модуль к `egrul.nalog.ru` для поиска свежих ИП (`326<КодРегиона>…`) и ООО (`126<КодРегиона>…`), автоматически включающийся при запуске с российского IP или при указании `RU_PROXY_URL`.
3. **`OpenContactsCollector` (`parser/collectors/open_contacts.py`)** — мониторинг лент новых карточек компаний и ИП в открытых бизнес-справочниках РФ + многопоточный обход корпоративных сайтов (главная, `/contacts`, `/rekvizity`, `/privacy`, `/oferta`) для извлечения проверенных телефонов `+7 (…)`, `8 (800) …`, email, ИНН/ОГРНИП, ссылок на WhatsApp и Telegram.

### Контур 2 — Подключаемые официальные API контрагентов и справочников
Как только вы добавляете любой из бесплатных/коммерческих ключей в GitHub Secrets (или в `.env`), они автоматически включаются в общий цикл:
1. **`DaDataCollector` (`DADATA_API_KEY`)** — до **10 000 запросов в сутки бесплатно** на [dadata.ru](https://dadata.ru). Ищет и `INDIVIDUAL` (ИП), и `LEGAL` (ООО) с фильтрацией строго по свежей дате регистрации (`state.registration_date`).
2. **`CheckoCollector` (`CHECKO_API_KEY`)** — до **100 запросов в сутки бесплатно** на [checko.ru](https://checko.ru/integration/api). Вытягивает свежие ИП и ООО вместе с блоком `Контакты.Тел`, `Емэйл` и `ВебСайт`.
3. **`ApiFnsCollector` (`APIFNS_KEY`)** — выборки через `api-fns.ru/api/search` со специальным фильтром `active+only_phone`.
4. **`TwoGisEnricher` (`TWOGIS_API_KEY`)** — дообогащает карточки без телефона через `catalog.api.2gis.com/3.0/items` по названию и региону.

## 💻 Возможности веб-панели на Here.now

1. **Фильтрация по всей РФ в реальном времени:**
   - Поиск по названию, ИНН, ОГРН/ОГРНИП, ФИО директора/ИП, городу или цифрам телефона;
   - Переключатели: **Все / ООО / ИП** и **Все / 📞 С телефоном / 📱 Мобильные +7(9XX) / ✉️ С Email / 🌐 С сайтом**;
   - Фильтры по субъекту РФ, отрасли ОКВЭД и этапу CRM.
2. **Встроенная мини-CRM для прозвона:**
   - Статусы (`Новый`, `В работе`, `Перезвонить`, `Клиент`, `Отказ`) + текстовые заметки менеджера с сохранением в `localStorage` и облачной синхронизацией через `here.now Site Data`;
   - Кнопки звонка в 1 клик (`tel:+7…`), быстрого перехода в **WhatsApp** (`wa.me/7…`) и проверки контрагента в Checko / Rusprofile / 2ГИС / ФНС.
3. **Вкладка «⚡ Живой поиск по API»:**
   - Позволяет делать мгновенные запросы новых ИП и ООО прямо из браузера по вашему ключу DaData + 2ГИС без ожидания крона.
4. **Экспорт в 1 клик:**
   - **📊 Excel (`.xls` SpreadsheetML)** с сохранением текстового формата ИНН и 13/15-значных ОГРН/ОГРНИП без потери цифр;
   - **📥 CSV (UTF-8 BOM, разделитель `;`)** для импорта в Bitrix24 / AmoCRM / автообзвон;
   - **📋 Копирование всех телефонов** текущей выборки в буфер обмена.

## 🚀 Настройка собственной копии в GitHub Actions

Для `BAKICH1/novoreg-parser` эти шаги уже выполнены. Инструкция ниже нужна только при переносе в другой репозиторий.

1. **Закрепите сайт на Here.now:**
   - Откройте вашу персональную ссылку `claimUrl` и войдите в бесплатный аккаунт.
   - Скопируйте API-ключ в панели [here.now/dashboard](https://here.now/dashboard).
2. **Создайте репозиторий на GitHub и загрузите туда содержимое папки `novoreg-parser`:**
   ```bash
   cd novoreg-parser
   git init
   git add .
   git commit -m "Initial commit: NovoReg 24/7 Parser"
   git branch -M main
   git remote add origin https://github.com/<ваш-аккаунт>/<ваш-репозиторий>.git
   git push -u origin main
   ```
3. **Добавьте секреты в GitHub (`Settings` → `Secrets and variables` → `Actions` → `New repository secret`):**
   - `HERENOW_SLUG` = `vivid-quill-yz5r`
   - `HERENOW_API_KEY` = ваш ключ `hnk_...` из панели `here.now`
   - *(По желанию для усиления сбора ИП и телефонов)*: `DADATA_API_KEY`, `CHECKO_API_KEY`, `TWOGIS_API_KEY`, `APIFNS_KEY`, `RU_PROXY_URL`.
4. **Активируйте Workflow:**
   - Откройте вкладку **Actions** в репозитории и нажмите **Run workflow** для первого тестового запуска. Далее крон (`.github/workflows/parser-cron.yml`) будет автоматически запускаться **по расписанию каждые 10 минут** (возможны задержки GitHub), пополнять базу и инкрементально обновлять ваш сайт `https://vivid-quill-yz5r.here.now/`.

## 🛠 Локальный запуск или запуск демоном на VPS

Парсер не требует установки сторонних библиотек (`pip install` не нужен — чистый Python 3.10+):

```bash
# Разовый прогон парсера + обновление сайта на here.now
python3 -m parser.main --publish

# Непрерывный режим демона 24/7 (каждые 15 минут)
python3 -m parser.main --daemon --interval 900 --publish

# Сохранять строго только записи с телефонами
python3 -m parser.main --only-phone --publish

# Принудительный деплой папки site/ на here.now
python3 scripts/deploy_herenow.py
```

```text
├── .github/workflows/parser-cron.yml  # Расписание каждые 10 минут в GitHub Actions

│   ├── models.py                      # Валидация ИНН/ОГРН и строгая нормализация телефонов РФ (+7)
│   ├── regions.py                     # Все 89 субъектов РФ и классификатор отраслей ОКВЭД-2
│   ├── state.py                       # Дедупликация, ротация регионов и генерация stats.json
│   ├── publisher.py                   # SHA-256 инкрементальный паблишер на here.now + Site Data API
│   └── collectors/
│       ├── open_egrul.py              # Бесплатный поиск по фронтиру ОГРН 2026 + прямой модуль ФНС
│       ├── open_contacts.py           # Сбор телефонов/email/мессенджеров из открытых каталогов и сайтов
│       ├── api_dadata.py              # Коннектор DaData API (ИП и ООО по дате регистрации)
│       ├── api_checko.py              # Коннектор Checko API v2 (ИП и ООО + официальные контакты)
│       ├── api_fns.py                 # Коннектор API-ФНС (фильтр active+only_phone)
│       └── enrich_2gis.py             # Дообогащение номеров и мессенджеров через 2ГИС API
├── scripts/deploy_herenow.py          # Скрипт публикации и обновления сайта на here.now
└── site/                              # Веб-приложение (опубликовано на here.now)
    ├── .herenow/data.json             # Манифест облачной базы данных here.now Site Data
    ├── index.html                     # Интерфейс CRM, Live API, аналитика и инструкция 24/7
    ├── styles.css                     # Адаптивные стили (тёмная и светлая темы)
    ├── app.js                         # Фильтры, мини-CRM, Live API запросы, выгрузка Excel/CSV
    ├── 404.html                       # Страница 404
    └── data/
        ├── leads.json                 # Собранная база новорегов ИП и ООО с контактами
        └── stats.json                 # Статистика и журнал прогонов парсера
```
