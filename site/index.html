Прямой запрос новых ИП и ООО через API

Дополнительно к автоматическому облачному сбору можно выполнять целевые запросы по нишам, фамилиям ИП и префиксам ОГРН прямо из браузера. Ключи хранятся только локально на вашем устройстве.

Готов к запуску. Укажите бесплатный токен DaData и нажмите «Запустить поиск».

Архитектура сбора и верификации «2-в-1»

Парсер объединяет открытые российские источники и официальные реестры контрагентов для проверки телефонов, статуса ликвидации, часов работы и Telegram:

1
Открытый контур (работает автономно без ключей)
Обход 43 городов РФ и многостраничных отраслевых рубрик через серверный прокси Cloudflare (/api/orgpage/*), разбор сайтов компаний (включая домены .рф), извлечение телефонов +7 (…), расписания работы и верификация аккаунтов @telegram.
2
Проверка закрытия организации в ФНС / Saby
По ИНН проверяется актуальный статус юридического лица или ИП в ЕГРЮЛ/ЕГРИП через контур /api/saby/* (действующая организация, в процессе ликвидации или закрыта), а также подтягиваются ФИО руководителя и ОГРН.
3
Подключаемые API контрагентов и 2ГИС
При указании бесплатных ключей DADATA_API_KEY, CHECKO_API_KEY, APIFNS_KEY и TWOGIS_API_KEY система дополнительно обогащает базу свежими регистрациями ИП/ООО, телефонами отделов продаж и графиком работы из 2ГИС.

Автономный облачный Edge-парсер на Here.now активен

Серверные прокси-маршруты .herenow/proxy.json и облачная база /.herenow/data/leads + /.herenow/data/harvest_state работают напрямую на сети Cloudflare. При открытии сайта, каждые 3 минуты в фоне и по кнопке «Подтянуть свежие» система обходит новые города и страницы рубрик, проверяет статус, часы работы и Telegram, и сохраняет карточки в облако.

Дополнительный внешний крон через GitHub Actions (по желанию)

Если требуется дополнительный сбор каждые 20 минут даже при полностью закрытом браузере, подключите готовый workflow .github/workflows/parser-cron.yml в своём GitHub-репозитории.

1
Постоянный хостинг Here.now и облачная БД Site Data

Сайт закреплён на постоянном домене без ограничения срока жизни. Ключ HERENOW_API_KEY доступен в панели here.now/dashboard.

2
Загрузите проект novoreg-parser в GitHub

В репозитории уже настроен файл .github/workflows/parser-cron.yml на стандартной библиотеке Python без внешних платных зависимостей.

3
Укажите секреты в Settings → Secrets and variables → Actions
HERENOW_SLUG = ваш-slug-сайта (первая часть адреса <slug>.here.now) HERENOW_API_KEY = hnk_ваш_ключ_из_here_now_dashboard # Опциональные бесплатные ключи для усиления контура "2-в-1" (ИП + ООО + телефоны): DADATA_API_KEY = токен с dadata.ru (10 000 запросов/день бесплатно) CHECKO_API_KEY = ключ с checko.ru (100 запросов/день бесплатно) TWOGIS_API_KEY = ключ 2ГИС API для автопоиска телефонов и часов работы APIFNS_KEY = ключ api-fns.ru (по желанию) RU_PROXY_URL = http://user:pass@ip:port (опционально для прямого доступа к egrul.nalog.ru)
