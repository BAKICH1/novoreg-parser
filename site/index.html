⚡ Мгновенный сбор свежих ИП и ООО прямо из браузера

Помимо фонового парсера 24/7 в GitHub Actions, вы можете в любой момент делать живые выборки новорегов по всей РФ прямо с этого сайта. Ключи сохраняются только локально в вашем браузере.

Готов к запуску. Введите бесплатный токен DaData (регистрация за 30 сек на dadata.ru) и нажмите «Запустить живой поиск сейчас».

Как работает архитектура «2-в-1» для поиска телефонов?

В официальных бесплатных выписках ФНС личные мобильные телефоны скрыты законом, поэтому наш парсер комбинирует сразу два контура сбора:

1
Контур 1 — Бесплатные открытые источники (работает сразу без ключей)
Поразрядный бинарный поиск свежего фронтира ОГРН 2026 года (126<Регион>…) по субъектам РФ + мониторинг лент новых компаний в открытых бизнес-каталогах РФ и обход корпоративных сайтов (подвал, контакты, политика оферты) для извлечения ИНН, ОГРН/ОГРНИП, рабочих телефонов +7 (…), email, WhatsApp и Telegram.
2
Контур 2 — Подключаемые API контрагентов и гео-справочников
При добавлении ключей DADATA_API_KEY (10 000 запр./сутки бесплатно), CHECKO_API_KEY (100 запр./сутки бесплатно), APIFNS_KEY (фильтр only_phone) и TWOGIS_API_KEY воркер автоматически вытягивает как свежие ИП (326…), так и ООО (126…) и обогащает их проверенными телефонами отделов продаж и руководителей.
3
Инкрементальная доставка на Here.now за 1 секунду
После каждого цикла SHA-256 паблишер отправляет на here.now только изменившиеся JSON-файлы и синхронизирует коллекцию встроенной облачной БД Site Data.

🚀 Постоянная работа 24/7 бесплатно через GitHub Actions + Here.now

Хостинг Here.now мгновенно раздаёт этот веб-интерфейс и встроенную облачную БД Site Data на глобальной сети Cloudflare, а фоновый Python-парсер запускается каждые 20 минут в бесплатном облаке GitHub Actions (без покупки VPS!) и автоматически пушит свежих новорегов на этот сайт.

1
Закрепите этот сайт на Here.now навсегда (бесплатно в 1 клик)

Перейдите по выданной вам ссылке claimUrl — сайт станет вечным (без 24-часового таймера) и активируется встроенная облачная БД /.herenow/data/crm_notes для командной работы менеджеров. В панели here.now/dashboard скопируйте ваш HERENOW_API_KEY.

2
Загрузите папку проекта novoreg-parser в ваш GitHub-репозиторий

В проекте уже готов файл .github/workflows/parser-cron.yml (не требует платных библиотек — работает на чистом стандартном Python за секунды).

3
Добавьте секреты в GitHub → Settings → Secrets and variables → Actions
HERENOW_SLUG = ваш-slug-сайта (первая часть адреса <slug>.here.now) HERENOW_API_KEY = hnk_ваш_ключ_из_here_now_dashboard # Опциональные бесплатные ключи для усиления контура "2-в-1" (ИП + ООО + телефоны): DADATA_API_KEY = токен с dadata.ru (10 000 запросов/день бесплатно) CHECKO_API_KEY = ключ с checko.ru (100 запросов/день бесплатно) TWOGIS_API_KEY = ключ 2ГИС API для автопоиска телефонов APIFNS_KEY = ключ api-fns.ru (по желанию) RU_PROXY_URL = http://user:pass@ip:port (опционально для прямого доступа к egrul.nalog.ru)
4
Готово! Парсер работает круглосуточно

Каждые 20 минут GitHub Actions будет находить новых ИП и ООО по регионам РФ, дообогащать телефоны, сохранять историю в репозитории и за 1 секунду обновлять ваш сайт на here.now. Также запустить сбор вне очереди можно одной кнопкой Run workflow во вкладке Actions.
